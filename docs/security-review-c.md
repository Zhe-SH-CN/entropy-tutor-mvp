## 本轮发现并修复的问题

1. **邀请过期事务回滚**：原实现先写 expired 再抛 409，导致整笔事务回滚。现先提交过期事实，再在事务外返回冲突。
2. **worker 数据模型不一致**：按真实 Job 的 `kind/availableAt/lockedAt` 实现原子领取，最多三次尝试、指数退避和 dead 终态。
3. **公开输入枚举错误**：前端授课模式改用 API 合同中的 `online/offline`，不依赖服务端猜测中文输入。
4. **候选曝光证据不足**：服务端返回 Top 3 不再记曝光；浏览器必须观察到卡片至少 50% 可见并持续 1 秒。
5. **事件字段不完整**：补齐需求、推荐过滤与延迟、邀请报价/响应耗时、见面异常、订单价格带、课次时长、学习状态 ID 等 properties，并统一 snake_case。
6. **移动端横向溢出**：长事件名通过网格自动最小尺寸把页面撑到 475px。改为 `minmax(0, 1fr)` 并允许网格子项收缩；页面恢复 390px，步骤条和事件表只在自身容器内滚动。
7. **生产弱配置可启动**：增加启动闸门，拒绝占位/弱 SESSION_SECRET、非法 BYOK key、HTTPS 未启用 Secure Cookie，以及公网明文 HTTP。

## 安全控制复核

- **身份与会话**：Argon2id 密码哈希；随机会话 token 只存 SHA-256 hash；HttpOnly Cookie；注销使服务端会话失效。
- **CSRF 与授权**：非 GET 请求校验 CSRF；家长、教师、运营均进行角色与资源所有权检查。B-01/D-01 覆盖 IDOR、未审核发布、单方见面和未确认课次等拒绝路径，同时检查无副作用。
- **注入与 XSS**：数据库访问使用 Prisma 参数化接口；React 默认转义用户文本，A-03 验证 HTML 输入只作为文本显示。未引入 `dangerouslySetInnerHTML`。
- **支付与并发**：订单 Idempotency-Key、支付回调 HMAC、数据库唯一约束和可序列化事务共同防止重复副作用；B-03 为真实并发入口测试。当前支付仍明确是沙箱。
- **BYOK**：AES-256-GCM 加密；密钥不回显、不写 localStorage；Base URL 仅允许 HTTPS 和公网解析地址，限制重定向、超时及响应大小。B-02/B-E2E-02 覆盖本机地址拒绝和密钥不落地。
- **事件隐私**：公共字段与 properties 规范化；拒单、取消、审核自由文本留在受控业务表，事件只写枚举原因；禁止把电话、详细地址、证件原文、支付敏感信息、AI 全文和评论写入事件。
- **秘密与数据交付**：`.env` 和 `.env.*` 被 Git 忽略，仅 `.env.example` 可提交；仓库种子均为合成数据，不包含三份原始调研附件中的个人联系方式或地址。

## 上线前仍必须完成

1. 当前仅为内部合成数据 Demo；没有真实教师/家庭试点，不能据此声称付费、续课、学习效果或 30 万流水成立。
2. 托管模型、真实支付/退款、真实视频会议均未接供应商验收；默认 Mock 与沙箱不能冒充生产成功。
3. 正式服务器需要独立强密钥、HTTPS、Secure Cookie、最小数据库权限、备份恢复、日志监控及公网限流/WAF；本地 `mvp/mvp` 与 CREATEDB 不得沿用。
4. Docker 与 GitHub Workflow 按本轮要求未推进，`infra/` 仍是未验证早期草稿。
5. 公开教师入驻表单未实现；待审核申请来自合成种子。该项在覆盖矩阵中单独披露，不计入“全部 PRD 已产品化”。

结论：当前版本适合创始团队内部演示、克隆安装和二次开发；不应直接作为公开生产服务上线。
