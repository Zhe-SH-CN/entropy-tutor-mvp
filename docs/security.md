# 安全模型

## 信任边界

- 浏览器和模型输出均视为不可信输入。
- 所有业务授权在 API 服务端执行。
- 数据库是唯一持久业务事实源；浏览器本地状态不用于全栈 Demo 的权威状态。
- 支付、会议和模型供应商通过独立适配器访问，Sandbox 不代表真实供应商已接通。

## 已实现控制

### 身份、会话与请求防护

- 密码使用 Argon2id 哈希。
- 随机会话令牌仅以 SHA-256 哈希形式持久化。
- 会话 Cookie 设置 HttpOnly 和 SameSite；HTTPS 部署必须启用 Secure。
- 非 GET 请求执行 CSRF 校验。
- CORS 使用来源 allowlist，Helmet 提供基础响应头防护。
- API 配置请求速率限制。

### 授权与数据访问

- 家长、教师和运营均执行角色检查及资源所有权检查。
- 数据库访问使用 Prisma 参数化接口。
- 邀请、关系、订单、课次和事件通过事务与唯一约束维护一致性。
- 订单 Idempotency-Key、支付回调 HMAC 和可序列化事务共同控制重复副作用。

### 前端与输出安全

- React 默认转义用户文本。
- 不使用 `dangerouslySetInnerHTML` 渲染业务内容。
- AI 内容保存为草稿并经教师确认，不直接生成可执行 HTML。
- 前端提交后立即清除 BYOK 密钥输入，密钥不进入 localStorage。

### BYOK 与 SSRF

- BYOK 密钥使用 AES-256-GCM 加密。
- 配置读取仅返回是否已保存密钥，不回显明文。
- Base URL 仅允许 HTTPS 和公网解析地址。
- 禁止环回、私网和链路本地目标，并限制重定向、超时及响应大小。

### 事件与隐私

- 事件具有幂等键和统一公共字段。
- 属性统一为 snake_case，仅保存状态、版本、计数、枚举原因和实体引用。
- 电话、详细地址、证件原文、支付敏感信息、AI 全文和自由文本评论不得进入事件。
- 自由文本保留在受控业务表中，不进入分析事件载荷。

### 运行配置

生产模式启动校验拒绝：

- 缺失或仍为占位符的必要配置；
- 过短的会话或支付回调秘密；
- 非 32 字节十六进制 BYOK 主密钥；
- HTTPS 来源未启用 Secure Cookie；
- 非本机明文 HTTP 来源。

## 数据分级

| 数据                     | 仓库策略               | 运行策略               |
| ------------------------ | ---------------------- | ---------------------- |
| 合成账号、教师和需求     | 允许，必须使用虚构身份 | 可用于 Demo            |
| 真实联系方式、地址、证件 | 禁止提交               | 当前产品不应用于采集   |
| 真实支付与供应商秘密     | 禁止提交               | 仅通过受控环境配置     |
| AI 草稿与报告            | 仅允许合成内容         | 保存在受控业务表       |
| 数据库转储与原始调研名单 | 禁止提交               | 按内部数据制度单独保护 |

## 部署边界

公开演示凭据意味着任何能访问页面的人都可以操作合成数据。部署必须限制在受控团队范围内，并关闭不必要的主机端口。

面向真实用户前仍需完成：真实账号开通、HTTPS、秘密管理、最小数据库权限、日志监控、备份恢复、公网滥用防护，以及模型、支付、退款和视频会议供应商验收。

公开教师入驻表单、真实通知渠道、真实退款和真实会议资源不在当前能力范围内。
