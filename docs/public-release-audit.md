## 有意保留、不能误判为秘密的内容

- `DemoPass123!` 与 `parent/teacher/ops@demo.test` 是合成演示凭据，不是泄漏；但任何能访问部署页面的人都能使用它们。
- `postgresql://mvp:mvp@127.0.0.1:5432/...` 只用于本地开发/测试，文档明确禁止沿用到正式环境。
- 测试里的 `super-secret-demo-key`、`synthetic-key` 是失败路径夹具，不是有效供应商密钥。
- `.env.example` 的占位符会被生产启动校验拒绝，不能误当成已配置秘密。

## 公开后仍需遵守

1. 永不提交 `.env`、真实家庭/教师资料、原始调研名单、生产数据库转储或服务器凭据。
2. 公共仓库的 Workflow 只使用 GitHub-hosted runner、最小只读权限和合成数据；不把生产秘密暴露给 PR 构建，不使用自托管 runner 执行不可信 PR。
3. 若历史提交未来误含真实秘密，仅删除当前文件不够，应立即轮换秘密并清理历史。
4. 对外真实试点前必须替换统一演示认证、关闭种子入口、补真实用户管理和访问控制；当前版本只用于内部演示。
