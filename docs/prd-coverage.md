# PRD 内部 Demo 覆盖矩阵

对照在线 PRD revision 13 与当前工作区。状态只描述代码和实际测试，不代表商业效果已经成立。

| 范围 | 内部 Demo 状态 | 代码与验收证据 | 边界 |
|---|---|---|---|
| 三角色页面流 | 已实现 | `/server-demo`；Chromium B-E2E-01、D-E2E-01 | `/`、`/parent`、`/teacher`、`/ops` 是较早 localStorage 切片；真实全栈统一走 `/server-demo` |
| 登录、会话、CSRF、资源授权 | 已实现 | Argon2id、随机会话哈希、HttpOnly Cookie；B-01/B-02 | 生产仍需 HTTPS、Secure Cookie 和独立强密钥 |
| 需求创建、Mock 结构化、家长确认 | 已实现 | `POST /demands/*`；D-01、D-E2E-01 | 未确认需求不能推荐 |
| 教师档案与审核 | 已实现 | 运营审核/暂停；D-01、D-E2E-01 | 待审核申请和档案为合成种子；未做公开教师入驻表单 |
| 教师可授时间与容量 | 已实现 | 30 天新鲜度过滤、满载过滤；D-01 | 日历仅是结构化 slot，不是第三方日历同步 |
| 双向 Top 3 推荐 | 已实现 | `40P+20E+20R+20C-10B-10L²+X`；共享规则 13 项 | 公开资料未证明竞品使用同一算法，这是本产品的可解释初始规则 |
| 冷启动、探索配额、满载硬过滤 | 已实现 | 先验收缩、滚动 7 日探索配额、L 平方扣分；C-01 | 配额是候选返回口径，不伪装成真实曝光口径 |
| 推荐快照与回放 | 已实现 | 输入、选项、评分和规则版本持久化；C-01 | 人工改派不改历史快照 |
| 候选真实曝光与选择 | 已实现 | IntersectionObserver ≥50% 且 1 秒；D-01、D-E2E-01 | 服务端返回 Top 3 时不生成曝光事件 |
| 邀请接受、拒单、12 小时过期 | 已实现 | 状态机与 worker；D-01 | 过期为 system/worker 事件，不混称教师主动拒绝 |
| 双方见面与关系建立 | 已实现 | 双方都继续才建立关系；B-01、B-E2E-01 | 单方意愿不建立关系 |
| 见面改期、取消、no_show | 已实现 | 异常状态与追加事件；D-01 | 会议链接为沙箱 `.invalid` 地址 |
| 人工改派 | 已实现 | 追加 ManualOverride 和事件；D-01、D-E2E-01 | 不回写原推荐分数 |
| 订单与支付 | 沙箱已实现 | 1—4 课、订单与回调并发幂等；B-01/B-03 | 未接真实支付、退款或人工核验 |
| 排课、记课与课次确认 | 已实现 | 排课冲突键、教师记课、家长/运营确认；B-01/D-01 | 未确认课次不计第二/第四课 |
| 取消、no_show 与同师重排序 | 已实现 | 不占正式课序号；D-01 | 不是真实日历供应商排课 |
| 关系备课卡与下一课承接 | 已实现 | 关系级 Artifact、rawContent、教师确认；D-01/D-E2E-01 | AI 只生成草稿 |
| 学习状态建议与教师确认 | 已实现 | `unverified → teacher_confirmed`；D-01/D-E2E-01 | 未确认状态不得进入排序 |
| 课后报告、发送与家长已读 | 已实现 | 教师确认后可见、站内发送事件、已读时间；B-01/D-01 | 无短信、微信或邮件供应商 |
| 家长继续、暂停、换老师 | 已实现 | 行为与主观反馈分表；换老师关联新草稿；D-01 | 自由评论不进入事件 properties |
| AI 失败降级与质量评审 | 已实现 | 失败事件、运营 rubric 评审；D-01/D-E2E-01 | 不等于真实模型质量已验收 |
| 可信推荐特征反哺 | 已实现 | 课次确认后重算出勤、取消、报告及时性；D-01 | LLM 情绪词和主观教师评分不进入排序 |
| 30 日成熟 cohort 与北极星 | 已实现 | 成熟需求、已支付、同师第四次已完成课；C-01 | 无成熟需求返回 `null`，不拿 0 冒充结果 |
| 异常队列与 worker | 已实现 | 原子领取、三次尝试、指数退避、dead；D-01 | 外部通知/邮件 worker 仍是适配器占位 |
| 完整事件口径 | 已实现 | 39 个事件字典、公共字段、snake_case properties；D-01 | 教师申请事件来自合成种子，公开入驻表单未实现 |
| Mock / 托管 / BYOK 模型网关 | 接口已实现 | AES-256-GCM、HTTPS 公网解析限制、超时与大小限制；B-02 | 默认 Mock；托管模型凭据、预算和真实质量未验证 |
| 桌面与移动端 | 已实现 | 1440px 与 390px Chromium；截图存 `docs/screenshots/` | 最终审美仍需创始团队验收 |
| Node + PostgreSQL 迁移协作 | 已实现 | README、锁文件、Prisma migrations、合成 seed | 不需要复制云主机数据库 |
| Docker / GitHub Workflow | 本轮未推进 | `infra/` 仅早期草稿 | 未执行容器构建或 CI，不作为当前验收项 |
| 真实教师/家庭试点 | 未进行 | 只能由线下试点验证 | 合成数据不能证明付费、续课、学习效果或 30 万流水 |

## 结论

当前交付边界是：**可供创始团队内部交流、可测试、可克隆后进行二次开发的完整合成数据全栈 Demo**。它不是已公开部署、已接真实供应商、已获真实用户验证的生产 MVP。
