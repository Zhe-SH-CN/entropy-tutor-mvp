# A/B/C 行为合同与阶段门禁

权威来源：《AI原生家教平台 MVP PRD v0.2》与 ADR-001。所有数据均为合成数据；不得导入附件中的联系方式或详细地址。

## 阶段 A：可点击 Demo

- 家长可从创建/确认需求进入候选，查看具体时段、模式、报价及七项分数解释。
- rule_v0.2 使用 40P＋20E＋20R＋20C－10B－10L²＋X；硬过滤先于评分；无候选不伪造 Top 3。
- 教师可接受/拒绝邀请，维护可用性，完成见面、备课和记课确认。
- 运营可改派并填写原因，观察事件与异常。
- AI Mock 必须明确标识；未确认输出不得对家长生效。
- 演示可到达同师第四课与基础看板。
- 门禁：规则单元测试、关键页面 E2E、构建、响应式/键盘检查；安全审查覆盖 XSS、输入校验、Mock 标识、敏感信息与依赖。

## 阶段 B：真实业务闭环

- 数据库持久化、角色登录、服务端 RBAC/资源归属、会话和 CSRF 防护生效。
- 邀请接受、订单、排课和容量具有事务/唯一约束；竞态不能产生重叠有效课次。
- 事件具有幂等键；重启后业务与事件仍可读取。
- 托管 OpenAI 兼容模型与 BYOK 共用 Model Gateway；无密钥时只能使用明确 Mock。
- BYOK 密钥仅服务端使用，密文存储、不可回显；Base URL 通过 SSRF 防护。
- 支付和会议提供 Sandbox 适配；回调验签与幂等通过公开入口验证，未接真实供应商须披露。
- 门禁：API/数据库集成测试、越权/IDOR、CSRF/CORS、认证、并发、SSRF、密钥日志、支付幂等、AI 输出与依赖安全审查。

## 阶段 C：分析与部署

- 看板可由事件/课次重算有效需求、候选覆盖、见面、首课、第二/第四课、报告及时与 AI 指标。
- 未满 30 日 cohort 不进入北极星最终结果；探索、改派和换老师原因可拆解。
- 推荐可凭输入快照与 rule_v0.2 回放；规则变化创建新版本。
- 提供备份/恢复说明、环境变量校验、健康检查、容器配置和本地生产模式运行方式。
- 门禁：全量回归、E2E、事件重算一致性、依赖/密钥/容器扫描、OWASP 重点路径人工审查；未能执行的检查逐项披露，不以扫描代替安全判断。
